최고 모델을 흉내 내는 나무

6편의 판정 앱에는 사람이 읽을 수 있는 조건문만 넣습니다. 그런데 4편의 최종 모델(로지스틱 + 임계값 0.405)은 58개 특성의 가중합 계산식입니다. 성능을 지키면서 조건문을 얻는 방법은 하나입니다. 나무에게 실제 정답 대신 최종 모델의 판정을 가르치는 것, 대리모델(surrogate)입니다.

조교

로지스틱이 제일 좋았는데, 현장에는 계산기가 없대요. 그럼 성능을 포기해야 해요?

박사NPC

포기하지 않습니다. 나무에게 “로지스틱이라면 뭐라고 판정할까?”를 배우게 하면, 판정 기준을 조건문으로 물려받습니다.

2

안 보이는 담장을 지도로 그리기Mapping an invisible fence

곡선은 계단으로 근사할 수 있지만, 완전히 같아지지는 않습니다.

안개 낀 밭의 담장. 밭 한가운데 담장(선생님 모델의 경계)이 있는데 안개 때문에 보이지 않습니다. 밭 곳곳의 사람(학습 고객)에게 “당신은 담장 안쪽입니까?”(선생님 모델의 판정)를 묻고 답을 지도에 찍으면, 답이 갈리는 자리에 담장이 드러납니다. 그 지도를 조건문으로 그리는 것이 나무입니다.

아래 그림의 선생님은 곡선 경계를 그리는 SVC(RBF)입니다. 곡선과 계단의 차이가 잘 보이도록 특성 2개 평면에서 보여 줍니다. 실제 대리모델(4~6절)의 선생님은 58개 특성 로지스틱입니다.

3

방법: 정답 자리에 선생님의 판정을One-line difference

대리모델 = 선생님 모델의 판정을 정답처럼 배우는 쉬운 모델.

코드는 한 줄만 다릅니다.

tree.fit(X_train, y_train)                    # 보통 나무: 실제 청구 여부를 배운다 (3편)
tree.fit(X_train, teacher_train)              # 대리모델: 로지스틱의 판정을 배운다
# teacher_train = (로지스틱 확률 >= 0.405)  ← 4편에서 정한 임계값까지 포함

정확도 · 재현율

나무의 판정 vs 실제 청구 여부. 현실을 얼마나 맞히나.

충실도 (fidelity)

나무의 판정 vs 로지스틱의 판정. 선생님을 얼마나 잘 흉내 냈나.

fidelity = (tree.predict(X) == teacher(X)).mean()

충실도뜻결론
0.95 이상선생님을 잘 재현규칙 앱에 써도 된다
0.85 ~ 0.95아직 부족규칙을 늘려 다시
0.85 미만규칙으로는 어렵다다른 배포 방식 (6편)

나무는 표준화가 필요 없습니다. 그래서 대리모델은 표준화 전 원래 단위로 학습합니다. 그래야 규칙이 “순매출 1.3 표준편차”가 아니라 “순매출 80.5 초과”처럼 기준서에 그대로 적을 수 있는 숫자로 나옵니다. 데이터는 원본 학습 고객 50,660명만 씁니다(가상 고객을 만들지 않음).

설명용 모형인 것: 이 시리즈는 공개 학습용 여행자보험 데이터(63,326건)를 그대로 씁니다. 가상 데이터를 만들거나 데이터를 증강하지 않습니다. 브라우저 실습은 교육용 구현이라 정식 코드와 숫자가 조금 다를 수 있으며, 다른 경우 그 자리에 밝힙니다. 담장 비유 그림의 선생님은 특성 2개 SVC(RBF)이고, 실제 대리모델의 선생님은 58개 특성 로지스틱입니다.
